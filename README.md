# Flores para ti

Sitio estático con tres experiencias: Flores para mi bonita, Viaje de flores amarillas y Galaxia de flores amarillas.

## Ver localmente

Ejecuta `python -m http.server 8085` en la carpeta y abre http://localhost:8085.

La galaxia incluye cámara por arrastre, zoom con rueda o pellizco, controles de música y pausa. Los archivos de música se incluyen en el proyecto.
